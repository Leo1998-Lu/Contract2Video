# Human evaluation instructions

Compare two anonymized videos generated from the same prompt and shot budget. Randomize left/right order and use the same display settings for every pair.

Rate each pair on a 1–5 scale for:

1. preservation of entities and attributes;
2. event order and temporal continuity;
3. spatial and camera relation fidelity;
4. overall perceptual quality;
5. preference for the better grounded result.

Judge only the visible or audible media. Do not infer the method, model, or source from file names. Record an optional short reason. Store the pairing key separately from the anonymized labels. Do not reuse a clip in the same participant's repeated pair unless the protocol explicitly requires a reliability check.
